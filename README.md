# 野生动物追踪串号校正与计数台

面向野生动物视觉工程师的网页工具：纠正追踪串号（ID switch）造成的漏计 / 重复计数。
上传帧图片与检测框，标记“同只 / 异只”判断，调整关联代价参数，求解**全局最小**关联，
按轨迹条数给出动物计数；判断冲突时明确提示无解，不给计数。

## 快速启动（Docker Compose）

```bash
docker compose up --build
# 打开 http://localhost:8000
```

## 本地开发


## 使用流程

1. **数据**：上传 1~10 张帧图片 + 1 个检测 JSON（≤30 框），或点击“加载交叉遮挡示例”。
2. **按帧查看与标记**：←/→ 键或按钮切换帧；点击两个检测框（可跨帧）后选择
   “标记为同只 / 异只”，可随时清除。
3. **点选分割**：在查看区进入“点选分割”，点选当前帧中的一个检测框，
   框内左键加前景点（≥2 个）、右键加背景点（≥1 个），自动生成单块动物掩膜，
   叠加半透明填充与轮廓，并显示动物实际可见的**原图像素面积**。详见下文。
4. **代价参数**：距离权重、外观权重、每条新轨迹罚分，均可调。
5. **求解**：点击“计算最优关联”。计算期间可继续修改判断与参数；
   任何修改会立即撤下旧结果，迟到的旧结果不会覆盖新输入（按输入版本号校验）。

## 点选分割（检测框内可见像素面积）

用于遮挡画面复核：选一个已有检测框，在框内标注前景/背景种子点，
依据**像素颜色与邻接关系**生成单块动物掩膜，给出原图像素面积（不缩放，1:1 裁剪）。

- 交互：进入点选分割后，左键在框内添加前景点（至少 2 处），右键添加背景点（至少 1 处）；
  提供“撤销上一点 / 清除”。换框、换帧或改动任一标点都会立即撤下旧掩膜，
  在途请求的迟到结果按标点令牌丢弃，不会覆盖新标点。
- 算法（仅 Pillow / NumPy / SciPy）：
  1. Pillow 解码整帧并按检测框裁剪；裁剪任一边超过 **256 像素**或图片解码失败直接提示；
  2. 以前景/背景种子（含 3×3 邻域）分别估计 RGB 对角高斯颜色模型；
  3. 逐像素计算前景对背景的对数似然比，取似然比 > 0 为前景候选；
  4. `scipy.ndimage.label` 做 8 邻接连通域分析，只保留包含**全部**前景点的那一个
     连通域作为唯一掩膜（单块动物）；背景点必须被判为背景，不得进入掩膜。
- **不能可靠分割时明确提示且不给出面积**：
  - 纯色区域：前景/背景种子平均颜色一致，颜色无法区分前后景；
  - 颜色模型无法同时解释前景与背景种子；
  - 前景点分属不同连通域，无法连成一块；
  - 裁剪超过 256×256、图片解码失败、标点不足或落在框外。
- 分割只读取帧图像与检测框，**不修改检测 JSON、身份判断、轨迹与计数**，
  也不推进会话版本号。面积单位为原图像素（掩膜像素计数）。

## 检测 JSON 格式

```json
{
  "detections": [
    {"id": "b1", "frame": 0, "rect": [x, y, w, h], "vector": [0.8, 0.1, 0.2]}
  ]
}
```

- `id`：框号（字符串或数字，全局唯一）
- `frame`：帧号，0 起，须小于上传图片数
- `rect`：`[x, y, 宽, 高]`，宽高为正
- `vector`：非零外观向量，所有框维度一致（≤512 维）

会话内可下载当前检测 JSON：`GET /api/sessions/{sid}/detections.json`。

## 模型与求解

- 约束：每框恰属一条轨迹；同一轨迹每帧至多一框；轨迹内相邻框帧差 1~2 且时间递增。
- 关联代价：`w_dist × 框中心距离平方 + w_app × (1 − 余弦相似度)`。
- 目标：所有关联代价 + 轨迹条数 × 新轨迹罚分，求**全局最小**。
- 方法：整数线性规划（SciPy `milp` / HiGHS）。
  “同只”用单位流强制可达（同轨迹），“异只”用 0/1 割变量强制不可达。
- 判断相互冲突（如两框同帧却标同只、同只与异只传递冲突）时返回**无解**，
  界面明确提示且不显示动物计数。
- 动物数 = 轨迹条数。

## 内置交叉遮挡示例

6 帧画面：A（红）与 B（蓝）沿 X 形路径相向穿行，第 3 帧 B 被 A 遮挡缺失检测、
A 的外观向量被污染。正确结果为 2 条轨迹（2 只）：B 链需跨 2 帧连接（帧 2→帧 4），
遮挡点两侧两框位置极近，朴素最近邻会在交叉点串号。
默认参数（w_dist=1、w_app=10000、罚分=15000）针对该示例调优；
上传自有数据时请按图像尺度与外观向量区分度调整权重。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sessions` | 上传图片（`images`）+ 检测 JSON（`detections`），创建会话 |
| POST | `/api/example` | 创建交叉遮挡示例会话 |
| GET | `/api/sessions/{sid}` | 会话数据（含输入版本号） |
| GET | `/api/sessions/{sid}/frames/{i}` | 第 i 帧图像 |
| PUT | `/api/sessions/{sid}/judgments` | 整体替换同只/异只判断（版本 +1） |
| PUT | `/api/sessions/{sid}/params` | 更新代价参数（版本 +1） |
| POST | `/api/sessions/{sid}/solve` | 启动异步求解，返回任务 id 与输入版本 |
| POST | `/api/sessions/{sid}/segment` | 对点选分割提交异步任务（前景≥2、背景≥1，点须在框内），返回任务 id |
| GET | `/api/jobs/{job_id}` | 查询任务状态与结果（求解结果携带输入版本；分割结果含 `kind:"segment"`） |

点选分割成功结果：`{ok: true, crop: {x, y, width, height}, mask_rle: [...], area_px: n}`，
`mask_rle` 为 off/on 交替、以 off 开头的行程编码；不可靠时返回
`{ok: false, message: "中文原因"}`，不含面积字段。

## 说明与限制

- 会话与任务保存在进程内存中，重启即清空（单用户工具定位）。
- 上限：10 帧、30 框、200 条判断、外观向量 512 维。
- 点选分割：框内裁剪任一边超过 256 像素即拒绝；单类标点上限 200 个。
- 求解默认 60 秒时限；本规模（≤30 框）通常在毫秒级完成。
